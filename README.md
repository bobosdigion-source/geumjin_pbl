# geumjin_pbl

㈜금진 AI+PBL 훈련에서 만든 **시장·수출 동향** 웹페이지(`index.html`)를 GitHub Pages로 게시한 저장소입니다.

## 사이트 주소

**https://bobosdigion-source.github.io/geumjin_pbl/**

- 호스팅: GitHub Pages (Settings → Pages, 배포 브랜치 `main`, 경로 `/`)
- 이 저장소는 공개(Public)이므로 주소와 파일 내용을 누구나 볼 수 있습니다. 실제 업무 데이터나 비공개 자료는 올리지 마세요.
- 비공개 저장소로 바꾸면 GitHub Pages가 유료 플랜에서만 동작합니다. 비공개로 두려면 Cloudflare Workers 등 다른 호스팅을 사용하세요.

## 수정·배포

1. `index.html`을 수정해 `main` 브랜치에 commit·push 합니다.
2. 1~2분 뒤 위 주소에 반영됩니다.
